网迹 · 历史 / 书签 双 tab 全状态视觉稿10 个状态 · 1400px 画板 · 示意假数据

顶栏分段控件切换两个 tab：历史按域名聚合，书签按你在浏览器里整理的文件夹聚合（一张卡片 = 一个文件夹，按书签树顺序排列）。以下为完整静态呈现，所有控件无行为；配色、字号、间距沿用现有 styles.css 浅色 token。

01

02

    空态与边界s09 / empty-and-boundaries · 书签为空 / 空文件夹 / 特殊协议

    书签为空引导新建；空文件夹显示为空卡片而非隐藏；特殊 URL（chrome:// / file:// / javascript: 书签小工具）留在其所属文件夹卡片内，只展示不打开——协议白名单仅 http/https。§16.13 起不再有独立的「本地 / 其他」域名桶。

    边界规则说明协议白名单与不做的事
  • 协议白名单仅 http / https：chrome://、file://、javascript: 等特殊协议留在所属文件夹卡片内，行内标注「本地 / 其他 · 只展示」，只展示、不打开。
  • 空文件夹仍可见：空文件夹显示为空卡片并给「+ 新建子文件夹」入口，树形弹层里同样可见；修订了早期「空文件夹统一收进树弹层」的口径。
  • 本版明确不做：跨源「已收藏」标记、拖拽排序、撤销 / 回收站、导入导出、深色主题——不出现在任何界面中。

    tab 控件规格顶栏分段控件 · 切换不跳变

  • 位置：顶栏同一行，brand 之后、搜索框之前；不额外占纵向空间，两个 tab 高度恒定。
