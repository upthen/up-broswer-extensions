# 历史域名卡片墙 · 安装与使用

一个纯本地的浏览器扩展：把浏览历史按域名聚合成卡片，一个域名一张卡，支持全量搜索、按域名限定搜索、按域名清除记录。
不保存、不上传任何数据，不写入任何本地存储；**唯一的写操作**是你在卡片上二次确认后删除浏览器历史。

## 一、安装（Chrome / Edge，Chromium MV3）

1. 地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 打开右上角的「开发者模式」。
3. 点「加载已解压的扩展程序」，选择**包含 `manifest.json` 的那一层目录**（仓库里的 `history-by-domain/` 子目录；本机为 `D:/Personal/history-by-domain/history-by-domain`）。**不要选仓库根目录**——那里只有 README / LICENSE，没有 `manifest.json`，Chrome 会报清单文件缺失。
4. 安装完成后，把图标固定到工具栏（可选）。

安装时浏览器会提示以下权限，均属预期：

| 提示 | 来源 | 用途 |
|---|---|---|
| 读取和更改您的浏览记录 | `history` | 读取历史以聚合成卡片、执行搜索；**以及在你二次确认后按域名删除历史** |
| 网站图标相关提示 | `favicon` | 让卡片显示站点图标，由浏览器自身缓存提供 |

扩展**没有**声明 `tabs`、`<all_urls>`、`storage`、content script 或任何网络/主机权限。
新增的清除功能**没有增加任何权限**——`history` 权限本身已包含 `chrome.history.deleteUrl`。
代码里只有这一处写操作，且必须走「统计 → 确认 → 删除」两步，不会静默删任何记录。

修改代码后，回到扩展页点该扩展卡片上的「刷新」即可生效，无需构建、无需重新打包。

## 二、打开方式

| 方式 | 说明 |
|---|---|
| 点工具栏图标 | 打开面板；**已打开则直接切过去，不会重复开标签** |
| `Alt+H` | 同上。若快捷键被占用，在 `chrome://extensions/shortcuts` 里改 |
| 地址栏输入 `h 关键词` 后回车 | 直接带着关键词打开面板并搜索 |

## 三、界面说明

- **首屏**：只读取最近 200 条历史，按注册域名（eTLD+1）聚成卡片，按最近访问时间排序。
- **卡片**：显示 favicon、域名、页面数 / 访问次数 / 最近访问时间；正面常驻最近 3 个页面标题，点标题在新标签打开。右上角有两个淡色图标：**放大镜**（只搜这个域名）与 **垃圾桶**（清除这个域名，鼠标移上去变红）。「本地 / 其他」桶没有这两个图标。
- **展开规则**（避免卡片被撑得特别长）：
  - 4～10 页：`查看全部 N 页` 在卡内展开；展开后底部还有「在新页查看该域名完整列表」，可看该域名的全量历史。
  - 超过 10 页：按钮变成「在新页查看全部 N 页 ↗」，**新开一个标签页**摊平展示完整列表，卡片本身不展开。
  - 详情页顶部输入框**仅在该域名内搜索**：支持多词（空格分隔、需全部命中）、命中词高亮，纯本地匹配、不再查历史；点标题新标签打开；左上角「← 返回卡片墙」会直接切回已打开的面板，不重复开标签；若面板已被关掉，则自动新开一个卡片墙（v1.2.1 起不会点了没反应）。
- **只搜某一个域名**：点卡片头部的放大镜图标 → 顶部出现「仅在 xxx 内搜索」的标签，卡片墙切换成全宽结果列表，之后搜索框里输入的文字**只在这个域名（含所有子域）的历史里匹配**。
  - 进入时若搜索框已有文字，直接拿它当域内首查，不用重打。
  - 首次进入先用已有数据秒出结果，再后台补全约 90 天的全部记录（状态行有 `N/13 周` 进度，补全后列表自动变长）；再次进入同一域名走缓存，零等待。
  - 输入即搜，单字也能用；支持多词（空格分隔、需全部命中）、中文、大小写不敏感，命中词在标题和网址里高亮。清空输入就是该域名的完整列表。
  - 点标签上的 × 或按 `Esc` 退出，**当前这个词会自动扩大到全局再搜一次**，不用重打。标签右侧「在新页打开 ↗」可把结果连同关键词带到独立标签页。
- **清除某域名的全部历史**：点卡片右上角清除按钮 → 卡片内先显示统计进度（扫描约 90 天全量，**纯只读**）→ 出现确认条，写明域名、页面数、累计访问次数和「不可撤销」→ 点「确认删除」才真正执行。全程随时可「取消」。
  - **注意：删除范围是整个注册域名及其所有子域。** 清 `google.com` 会连 `mail.google.com`、`drive.google.com` 一起清掉，确认条里也写明了这一点。
  - **注意：不可恢复。** 直接删的是浏览器自身历史，没有撤销、回收站或备份。确认前请看清确认条上的数字。
  - 「本地 / 其他」桶没有清除按钮（里面混着 `chrome://`、`file://`、localhost、内网主机，不是「某域名」）。
  - 详情页只读，清除入口只在卡片墙的卡片上。
- **搜索框**：输入 ≥ 2 个字符后自动搜索（200ms 防抖），范围覆盖浏览器保存的全部历史（约 90 天），匹配域名、URL 和页面标题。搜索时卡片墙原地变形，清空即还原。
- **加载全部域名**：按周分段拉取 90 天全量历史，进度可见；过程中界面保持可交互。
- **其它 N 个域名**：只访问过一次、且超过 7 天没再打开的偶遇域名会折叠在这里，不占主墙；想找它们仍然可以靠搜索。

## 四、边界与已知限制

- 浏览器历史一般只保留约 90 天；**清除浏览器历史后，卡片墙会跟着变空**。
- 无痕窗口的访问记录不进浏览器历史，因此不会出现在这里。
- 搜索只匹配 URL 与页面标题，**不含网页正文，也不支持拼音 / 正则 / 模糊容错**。很多页面标题是「首页」「Dashboard」，这类站可能搜不回来——这是当前方案最大的找回率限制。
- 每个页面只展示最后一次访问时间，没有完整访问时间线。
- 子域会合并到主域（`mail.google.com` 和 `docs.google.com` 是同一张卡）；`foo.github.io`、`bar.github.io` 这类多用户托管域各自独立成卡。
- **清除操作不可撤销**，范围以约 90 天内的全量分段扫描为准；极端情况下（Chrome 内部截断查询上限）可能漏删个别页面，删完可在浏览器自带历史页复核。
- 插件不监听历史删除事件：在浏览器设置里手动清历史、或详情页开着时在主面板删除，另一个标签页不会自动刷新，切回后按 F5 即可。
- **域内搜索的缓存是内存快照**：锁定域名后若期间在别处新访问了该站、或删过历史，缓存不会自动更新；退出再进入同一域名仍走缓存，按 F5 刷新面板可拿到最新数据。
- 域内搜索同样只匹配标题与网址，**不搜网页正文，不支持拼音 / 正则**；范围以约 90 天内可枚举的记录为限。
- 不做隐私/敏感域名过滤：卡片墙比浏览器自带历史页醒目得多，**投屏或旁人在场时请留意**。
- 仅支持 Chromium 系（Chrome / Edge），不支持 Firefox / Safari。

## 五、卸载与排查

- 卸载：在扩展页点「移除」即可，没有任何残留数据（插件从未写入过存储；清除操作删的是浏览器自身的历史，与插件无关）。
- 面板空白：确认浏览器里确实有历史记录；打开面板的开发者工具（F12）看 Console 是否有报错。
- 搜不到老记录：确认没有清过历史；本插件的搜索始终传 `startTime: 0`，不受 Chrome 默认「最近 24 小时」限制。
- 图标不显示：站点 favicon 由浏览器缓存提供，历史过久的站点可能取不到图，会回退成域名首字母占位块。
- 清除后卡片没消失：按 F5 刷新；若仍在，说明该 URL 未被 `deleteUrl` 命中，看 Console 是否有 `[history] deleteUrl failed` 警告。
- 域内搜索结果偏少：首次进入时后台可能仍在补全（状态行有 `N/13 周` 进度），补全完成后会自动刷新；若刚清过该域名历史，按 F5 重进。
- 点图标却跳到详情页：正常应 focus 卡片墙；若出现此情况，检查 `detail.js` 是否误注册了 `onMessage` 监听（它会抢答单实例握手）。
- 「← 返回卡片墙」点了没反应（v1.2.1 已修）：先在扩展页点「刷新」，并**关掉旧的详情标签重新打开**（旧页面仍加载着旧版模块）。修复后该按钮由详情页自己完成聚焦，Console 会打印 `[panel-focus] result: focused` 或 `created`；若显示 `failed`，说明连新标签都开不了，看 Console 的 `[panel-focus] failed to open panel`。

详细设计与验收标准见同目录 `SPEC.md`（v1.2.1）。
