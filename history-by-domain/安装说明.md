# 网迹 · 安装与使用

一个纯本地的浏览器扩展：把**浏览历史按域名**、**书签按你自己的文件夹**、**当前打开的标签页按站点**聚合成卡片，顶栏一个分段控件在「标签页 / 书签 / 历史」三个 tab 间切换（标签页 v1.4.0 新增，v1.5.1 起排第一位并作为默认视图）。
不保存、不上传任何数据，不写入任何本地存储；写操作都由你逐次点击触发——按域名删除浏览器历史、管理浏览器书签、关闭浏览器标签页。

## 一、安装（Chrome / Edge，Chromium MV3）

1. 地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 打开右上角的「开发者模式」。
3. 点「加载已解压的扩展程序」，选择**包含 `manifest.json` 的那一层目录**（仓库里的 `history-by-domain/` 子目录；本机为 `D:/Personal/up-broswer-extensions/history-by-domain`）。**不要选仓库根目录**——那里没有 `manifest.json`，Chrome 会报清单文件缺失。
4. 安装完成后，把图标固定到工具栏（可选）。

安装时浏览器会提示以下权限，均属预期：

| 提示 | 来源 | 用途 |
|---|---|---|
| 读取和更改您的浏览记录 | `history` | 读取历史以聚合成卡片、执行搜索；**以及在你二次确认后按域名删除历史** |
| 读取和更改您的书签 | `bookmarks` | **v1.3.0 新增**。读取书签树以聚合成卡片、执行搜索；在你点击新建 / 改名 / 移动 / 删除时写入。**即使只浏览书签也必须声明此权限**，所以警告文案带「更改」二字 |
| 标签页相关提示 | `tabs` | **v1.4.0 新增**。只读取当前已打开标签页的网址、标题与图标，用来按站点（主机名）分组。它**不给**网页正文、不给注入脚本的能力 |
| 网站图标相关提示 | `favicon` | 让卡片显示站点图标，由浏览器自身缓存提供 |

扩展**没有**声明 `<all_urls>`、`storage`、`activeTab`、content script 或任何网络 / 主机权限；不监听历史、书签或标签页的变更事件、不常驻后台。
按域名清除历史**没有增加权限**——`history` 权限本身已包含 `chrome.history.deleteUrl`。
三类写操作都必须由你点击触发：清除历史走「统计 → 确认 → 删除」两步；删除书签 / 文件夹走「统计子树 → 确认 → 删除」两步；关闭标签页**一次点击即执行**（v1.5.3 起不再弹确认条，误关可用 `Ctrl+Shift+T` 恢复）。不会静默写入。

> 从 v1.3.0 升级到 v1.4.0 时新增了 `tabs` 权限，Chrome 可能暂时停用扩展并要求你确认，属正常现象。请务必在扩展页点该扩展卡片上的「刷新」，并**关掉旧面板标签重新打开**，否则旧页面仍跑旧模块。
>
> v1.5.0 **没有新增任何权限**，但改了标签页的分组与界面，同样要在扩展页点「刷新」并关掉旧面板重开，否则看到的还是旧样式。
>
> v1.5.1 只是把顶栏顺序调成「标签页 / 书签 / 历史」并把默认落点改成标签页，同样刷新扩展 + 关掉旧面板重开即可。
>
> v1.5.2 修了标签页行的悬浮底色（原来只亮标题一半，右侧按钮区不变色），同样刷新扩展 + 关掉旧面板重开即可。
>
> v1.5.4 把标签页卡片改成「一次全展开 + 瀑布流」：不再需要点「展开全部」，卡片按标签数从多到少排、矮卡自动补空。同样刷新扩展 + 关掉旧面板重开即可。
>
> v1.5.3 去掉了标签页批量关闭的二次确认（卡头 ×、「关闭其他」现在点一下就直接关），关完会提示关了几个、可用 `Ctrl+Shift+T` 恢复。同样刷新扩展 + 关掉旧面板重开即可。

修改代码后同样在扩展页点「刷新」即可生效，无需构建、无需重新打包。

## 二、打开方式

| 方式 | 说明 |
|---|---|
| 点工具栏图标 | 打开面板；**已打开则直接切过去，不会重复开标签** |
| `Alt+H` | 同上。若快捷键被占用，在 `chrome://extensions/shortcuts` 里改 |
| 地址栏输入 `h 关键词` 后回车 | 直接带着关键词打开面板并搜索（作用于当前 tab） |

面板默认落在「标签页」tab（最常用，也是顶栏第一个）；切到「书签」或「历史」后在同一标签页内会记住，关掉标签页重开则回到标签页（不写任何存储）。也可用 `chrome-extension://<id>/index.html?tab=bookmarks` 或 `?tab=history` 直达对应 tab。

> 默认只读标签页，**不再在打开面板时读历史**；第一次切到「历史」才会读一次，之后再切回不会重复读。

## 三、界面说明

### 顶栏切换

brand 右侧的「历史 / 书签 / 标签页」分段控件切换三个 tab，不额外占纵向空间。三个 tab 都有搜索框、状态行与卡片墙，但**排法不同**：历史与标签页按域名聚合，书签按你在浏览器里整理的文件夹聚合（一张卡片 = 一个文件夹）。切换会保留搜索框里已输入的词并按新数据源重新查一次。删除统计或二次确认进行中，切换会被暂时禁用。

### 历史 tab（v1.2.1 行为不变）

- **首屏**：只读取最近 200 条历史，按注册域名（eTLD+1）聚成卡片，按最近访问时间排序。
- **卡片**：显示 favicon、域名、页面数 / 访问次数 / 最近访问时间；正面常驻最近 3 个页面标题，点标题在新标签打开。右上角有两个淡色图标：**放大镜**（只搜这个域名）与 **垃圾桶**（清除这个域名，鼠标移上去变红）。「本地 / 其他」桶没有这两个图标。
- **展开规则**：4～10 页在卡内展开；超过 10 页按钮变成「在新页查看全部 N 页 ↗」，新开标签页摊平展示完整列表。详情页顶部输入框仅在该域名内搜索，左上角「← 返回卡片墙」会切回已打开的面板。
- **只搜某一个域名**：点放大镜 → 顶部出现「仅在 xxx 内搜索」标签，卡片墙切换成全宽结果列表；首次进入先用已有数据秒出，再后台补全约 90 天全部记录（状态行有 `N/13 周` 进度）；输入即搜、单字也能用、多词需全部命中、命中词高亮；点 × 或 `Esc` 退出，当前词自动扩大到全局再搜一次。
- **清除某域名的全部历史**：点垃圾桶 → 卡片内先显示只读统计进度 → 出现确认条（写明域名、页面数、累计访问次数和「不可撤销」）→ 点「确认删除」才执行。**删除范围是整个注册域名及其所有子域，不可恢复，没有撤销 / 回收站 / 备份**。「本地 / 其他」桶没有清除按钮；详情页只读。
- **搜索框**：输入 ≥ 2 个字符后自动搜索（200ms 防抖），范围覆盖浏览器保存的全部历史（约 90 天）。
- **加载全部域名**：按周分段拉取 90 天全量历史，进度可见。
- **其它 N 个域名**：只访问过一次、且超过 7 天没再打开的偶遇域名折叠在这里。

### 书签 tab（v1.3.0 新增）

- **主视图是文件夹卡片墙**：一张卡片 = 一个书签文件夹，按你在 Chrome 书签管理器里排的顺序展示。卡片头写文件夹名、完整路径（如「书签栏 / 开发 / 工具」）和「N 个书签 · M 个子文件夹」，卡片里只放这个文件夹**直属**的书签，行内写「添加于 X 前」和域名。卡片底部可以点**子文件夹**继续往下找。书签没有「访问次数」，也没有「加载全部域名」和长尾折叠。
- **卡片右上角的放大镜**进入「仅在此文件夹内搜索」，范围含该文件夹的所有子文件夹；子文件夹很多时也可用状态行右侧的「文件夹」按钮打开完整树。空文件夹也会显示成空卡片，不会藏起来。
- **卡片右上角只有放大镜**（域内搜索），没有垃圾桶；清除历史的入口不会出现在书签 tab 里。
- **写操作**：鼠标移到某条书签上出现「改名 / 移动到… / 删除」；卡片头有文件夹的「改名 / + 子文件夹 / 删除」；状态行右侧有「+ 新建书签」「+ 新建文件夹」「文件夹」三个按钮。卡片级不提供批量删除。新建书签时网址只允许 http/https。
- **文件夹树弹层**：点「文件夹」打开，能看到完整文件夹结构（包括空文件夹），可新建 / 改名 / 删除 / 移动文件夹，同时也是「移动到…」的目标选择器。操作后有提示，弹层保持打开让你看见变化。
  - 「书签栏」「其他书签」是浏览器内置根节点，**改名 / 移动 / 删除不可用**（图标置灰），但在它们下面新建子项是可以的；「移动端书签」可以正常修改。
- **删除要两次确认**：行内先显示「正在统计…」，再显示「将删除『X』（含 N 个子文件夹 / M 个书签），此操作不可撤销」，点「确认删除」才真正执行。**删除文件夹会递归删掉整棵子树，不可恢复**。
- **搜索**：单字即搜（120ms 防抖）、多词需全部命中、中文可用、命中词高亮；能搜标题、网址和**文件夹名**。结果仍按文件夹分组展示，不会变回域名卡片。搜索全程不调用浏览器书签 API，状态行显示「命中 N / M 个书签」。注意这里与历史 tab 的「≥ 2 字」手感不同，是刻意取舍。
- **域内作用域 / 详情页**：放大镜进入后 chip 写「仅在 X 内搜索书签」，列表同样是全宽结果；「在新页打开 ↗」会打开只读的「书签详情」页，详情页里没有任何编辑入口。
- 书签数据每次切到该 tab、每次写操作成功后、以及切回标签页时都会重新读取一次，因此在浏览器自带书签管理器里的改动，切回面板就能看到。

### 标签页 tab（v1.4.0 新增；v1.5.0 调整分组与操作形态；v1.5.4 取消折叠改瀑布流）

- **不接管新标签页**：Ctrl+T 开的还是浏览器原生页面；这个 tab 只是面板里的第三种视图，切过去才读取一次标签数据，历史/书签首屏完全不受影响。
- **按站点成卡（v1.5.0 改动）**：一个主机名一张卡，`naui.united-imaging.com`、`ai-gw.united-imaging.com`、`uih.feishu.cn`、`www.feishu.cn` 各占一张，不再把同一主域下的不同应用合并。`chrome://`、`file://`、`localhost`、原生新标签页等归到末位的「本地 / 其他」。面板自身与详情页不会出现在列表里，避免把自己关掉。
- **卡片按标签数从多到少排**，组内按你在标签栏里的原始顺序；多窗口时每行标有窗口号，固定标签标「已固定」。
- **一次看全，不用展开（v1.5.4）**：每张卡直接铺满该站点的全部标签，不再有「默认 3 条 + 展开全部」这层。卡片高度因此参差，所以卡片墙改成了**瀑布流**——每张卡都放进当前最矮的那一列，矮卡自动补进高卡旁的缺口；窗口变窄会自动重排列数，≤640px 退成单列。
- **操作入口默认隐藏**：卡头右上角的关闭图标、每行右侧的两枚图标，都是**鼠标移到卡片/这一行上才出现**（键盘 Tab 聚焦也会出现），避免卡片显得拥挤和误点。
- **完整网址完全相同的标签会标「重复」**（含 `#hash` 与参数），只标第二份及以后，纯提示、不会自动关。
- **点一行**会跳到那个已经开着的标签页（必要时切换窗口），不会新开标签；`chrome://` / `file://` 也能跳。
- **三种关闭方式**：
  - 卡头右上角红色 ×（悬浮卡片出现）→ **一点即关**该站点在所有窗口的标签，**固定标签跳过**；
  - 行右侧第一枚图标（悬浮该行出现）「关闭其他」→ 一点即关，保留本行、关闭同站点其余标签，固定标签同样跳过；
  - 行右侧红色 ⊗「单独关闭」→ 一点即关，固定标签也能关。
  - v1.5.3 起没有二次确认条了（每次点两下太麻烦）：关完会弹提示告诉你关了几个、有几个固定标签被保留，误关可用 `Ctrl+Shift+T` 恢复；**「本地 / 其他」桶不能整组关，也没有「关闭其他」**，只能逐条关。
- **搜索**单字即搜、多词都要命中，纯内存过滤，不调用浏览器标签 API；`Esc` 清空。
- **刷新时机**：切到该 tab、切回面板、每次关闭后、点右上角的刷新图标。停留在该 tab 时，在别处新开或关掉标签不会自动刷新——这是为避免常驻监听特意做的取舍。

## 四、边界与已知限制

- 浏览器历史一般只保留约 90 天；**清除浏览器历史后，历史卡片墙会跟着变空**。书签没有 90 天限制。
- 无痕窗口的访问记录不进浏览器历史，因此不会出现在历史 tab。
- 搜索只匹配 URL / 页面标题（书签侧另加文件夹名），**不含网页正文，也不支持拼音 / 正则 / 模糊容错**。
- 每个历史页面只展示最后一次访问时间；书签只有添加时间，没有访问时间线。
- 子域会合并到主域（`mail.google.com` 和 `docs.google.com` 是同一张卡）；`foo.github.io`、`bar.github.io` 这类多用户托管域各自独立成卡。
- **历史与书签的删除都不可撤销**：历史删除范围以约 90 天内的全量分段扫描为准；书签删除范围以当前书签树的子树为准，删文件夹会递归删除。**关闭标签页不同**，可用 `Ctrl+Shift+T` 恢复，插件不提供撤销 / 回收站。
- 停留「标签页」tab 时，别处在其它窗口开关标签不会自动刷新，需切回可见或点「刷新」。
- 标签页按子域合并到主域，精简公共后缀表的小众后缀仍可能误合并；无痕窗口标签默认不可见；关掉某窗口全部标签会连带关闭该窗口（面板所在窗口因面板被排除而保留）。
- 插件**不监听**历史删除或书签变更事件。书签数据靠「切 tab / 写成功后 / 切回可见」重读兜底，别处的改动不会实时反映，切回面板即可看到；历史侧的域内缓存仍是内存快照，按 F5 刷新面板可拿最新数据。
- 三个 tab 的搜索手感不一致（历史 ≥2 字 + 原生召回，书签与标签页单字 + 内存硬过滤），是刻意取舍，详见 `SPEC.md` §16.5 与 §17.3。
- `bookmarks` 权限警告文案带「更改」，即使只浏览书签也会出现。
- 不做跨源「已收藏」标记、拖拽排序、撤销 / 回收站、书签导入导出。
- 不做隐私 / 敏感域名过滤：卡片墙比浏览器自带历史页醒目得多，**投屏或旁人在场时请留意**。
- 仅支持 Chromium 系（Chrome / Edge），不支持 Firefox / Safari。

## 五、卸载与排查

- 卸载：在扩展页点「移除」即可，没有任何残留数据（插件从未写入过存储；删除操作改的是浏览器自身的历史、书签与标签页，与插件无关）。
- 面板空白：确认浏览器里确实有历史或书签；打开面板的开发者工具（F12）看 Console 是否有报错。
- 搜不到老记录：确认没有清过历史；本插件的搜索始终传 `startTime: 0`，不受 Chrome 默认「最近 24 小时」限制。
- 书签 tab 为空：确认已授予 `bookmarks` 权限并在扩展页点过「刷新」；新增权限后旧标签页必须关掉重开。
- 图标不显示：站点 favicon 由浏览器缓存提供，历史过久的站点可能取不到图，会回退成域名首字母占位块。
- 清除后卡片没消失：按 F5 刷新；若仍在，说明该 URL 未被 `deleteUrl` 命中，看 Console 是否有 `[history] deleteUrl failed` 警告。
- 书签改动没生效：切回面板或重进书签 tab 会重读一次；若仍不对，看 Console 是否有写 API 的报错。
- 标签页 tab 为空或读取失败：确认已授予 `tabs` 权限并在扩展页点过「刷新」，然后关掉旧面板标签重新打开；看 Console 是否有 `[tabs] query failed`。
- 域内搜索结果偏少：首次进入时后台可能仍在补全（状态行有 `N/13 周` 进度），补全完成后会自动刷新。
- 点图标却跳到详情页：正常应 focus 卡片墙；若出现此情况，检查 `detail.js` 是否误注册了 `onMessage` 监听（它会抢答单实例握手）。
- 「← 返回卡片墙」点了没反应（v1.2.1 已修）：先在扩展页点「刷新」，并**关掉旧的详情标签重新打开**。

详细设计与验收标准见同目录 `SPEC.md`（**v1.5.4**，书签集中在 §16，标签页管理在 §17），视觉稿见 `design/mockup.html`。
