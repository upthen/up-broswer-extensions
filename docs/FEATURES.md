# 功能清单与可行性矩阵

> 目标站点：https://www.toolhelper.cn/JSON/JSONFormat （JSON 格式化工具）
> 判定原则：**能在用户本机浏览器里完成的，绝不上服务端。**

## 0. 结论速览

| 分类 | 数量 | 结论 |
| --- | --- | --- |
| A. 纯浏览器可做（复刻原站 P0） | 15 | v1 必做，零成本、零联网 |
| B. 纯浏览器可做（增强 P1） | 11 | v1.1 起分批做，同样零成本 |
| C. 需要服务端 | 7 | v1 全部不做，只预留接口位 |
| D. 纯浏览器做不了（需本地原生程序） | 8 | 不做，文档写清边界 |
| E. 可能产生费用 | 7 | v1 只涉及 C1（一次性 $5，可选） |

**v1 产品边界：0 后端、0 服务器、0 注册、0 费用、离线可用。**

## A. 纯浏览器可做 —— 复刻原站（P0，v1 必做）

| # | 功能 | 细节要求 | 难度 |
| --- | --- | --- | --- |
| A1 | 双栏编辑器 | 左输入右输出。CodeMirror 6：行号、JSON 语法高亮、括号匹配与自动闭合、代码折叠、错误波浪线、当前行高亮、Tab 缩进、自动换行开关 | 中 |
| A2 | 格式化 | 缩进可选 2 空格 / 4 空格 / Tab（原站默认 2 空格）；保留键原始顺序；自动剥离 BOM 与首尾空白 | 低 |
| A3 | 校验 | 失败给「行:列 + 中文原因」，编辑器内可定位、可点击跳转；成功显示「有效 JSON · 节点 N · 深度 D · 大小 X KB」 | 中 |
| A4 | 压缩 | 一键 minify，字符串内的空白/转义不误伤 | 低 |
| A5 | 修复 | 容错解析：`//` `/* */` 注释、尾逗号、单引号、无引号 key、全角引号、BOM、前后多余文本、`NaN/undefined`、数字前导 `+`/多前导零、缺逗号（尽力而为），修完给出「改了哪几处」的诊断列表 | 中高 |
| A6 | 键排序 | 升序 / 降序；递归所有层级；可选「仅对象」或「含数组内对象」；保持值不变 | 低 |
| A7 | 转义 / 反转义 | 添加转义：把整段 JSON 变成可嵌入代码的字符串字面量（`\n \t \" \\ \uXXXX` 等 8 类）；移除转义：还原为可读 JSON | 低 |
| A8 | 数据来源 | 示例数据、本地文件（点击选择 / 拖拽 / `Ctrl+V` 粘贴）、读取剪贴板；支持 `.json` `.jsonc` `.txt`；UTF-8 / UTF-16 自动识别 | 低 |
| A9 | 输出动作 | 复制、下载（格式化结果 / 压缩结果 / 换行风格可选）、清空、左右栏互换 | 低 |
| A10 | 全屏 | `F11` 进入全屏编辑，`Esc` 退出（与原站一致）；全屏时工具栏收起为悬浮条 | 低 |
| A11 | 折叠 | 折叠全部 / 展开全部 / 按层级折叠到第 N 层 | 低 |
| A12 | 查找 | `Ctrl+F` 普通查找；`Alt+F` 常驻查找栏（`Enter` 下一个、`Shift+Enter` 上一个、窗口不自动关闭）；命中计数与高亮 | 中 |
| A13 | 统计 | 字符数、行数、UTF-8 字节数、对象/数组/标量计数、最大深度、编辑耗时 | 低 |
| A14 | 主题 | 亮 / 暗 / 跟随系统（默认亮色，贴合 IDE）；字号 12–18 可调 | 低 |
| A15 | 本地历史 | 最近 20 条记录存 `chrome.storage.local`，可置顶、删除、一键恢复；可按容量上限自动清理 | 低 |

| # | 功能 | 说明 | 难度 |
| --- | --- | --- | --- |
| B1 | 树形视图 | 可折叠节点、类型徽标、数组索引、复制 JSONPath、点击定位源码 | 中 |

| B6 | 时间戳增强 | 识别 10/13 位时间戳与 ISO 串，悬浮显示本地时区/UTC 时间，可批量把指定字段转成可读时间 | 中 |
| B7 | 页面取词 | 右键菜单：格式化 / 压缩 / 校验选中文本；可「格式化后替换页面中选中的内容」；页面右下角悬浮球（可关闭） | 中 |

| B10 | Side Panel / 独立窗口 | 侧边栏模式便于对照网页；独立窗口当桌面小工具用 | 低 |

## C. 需要服务端（或第三方 API）

| # | 功能 | 为什么要服务端 | 备注 / 成本 |
| --- | --- | --- | --- |
| C1 | AI 智能修复 / 自然语言解释 / 自然语言查询 JSON / 生成 Mock 数据 | 要调 LLM，密钥不能下发到客户端 | 两种方案：① BYOK，用户自填 Key 存本地，我们零成本；② 我方代理，需服务器 + token 费用 |
| C2 | 账号与云端同步（历史、收藏、设置跨设备） | 需数据库 + 认证 | 可用 `chrome.storage.sync` 顶替「仅设置项」，100KB 配额 |
| C3 | 分享链接 / 团队片段库 | 需短链服务、存储、过期与权限 | 需域名 + 服务器 |
| C4 | 网络诊断类工具（IP 归属地、DNS、Whois、HTTP 探测） | 浏览器受同源/隐私策略限制，且这类数据本身来自第三方 API | 扩展虽可跨域 fetch，但 IP 归属/Whois 仍要第三方服务，免费额度外收费 |
| C5 | 超大数据（>200MB）稳定处理 | 浏览器内存上限，需服务端流式/分片 | 一般不做；Worker + 流式解析可撑到几十 MB |
| C6 | 付费 / 订阅校验 | 支付回调必须服务端验签 | 接 Stripe/Paddle，或 Chrome 内置支付 |
| C7 | 跨用户使用统计 / 远程配置下发 | 需埋点与配置中心 | 可先用本地开关替代 |

## D. 纯浏览器做不了（需 Native Messaging + 本地原生程序）

| # | 想做但做不到 | 原因 |
| --- | --- | --- |
| D1 | 系统级全局快捷键（在 VSCode/记事本里选中 JSON 直接格式化） | 浏览器只管自己窗口内的按键；系统级需原生程序 |
| D2 | 静默读写任意磁盘路径 / 自动保存到指定目录 | 沙箱限制。只能「用户手势选文件 + 下载目录」；`File System Access API` 可让用户授权一个目录，但每次会话仍要确认，且仅 Chromium 桌面版 |
| D3 | 开机自启 / 系统托盘常驻 / 秒级定时任务 | MV3 Service Worker 会被回收；`alarms` 最小 1 分钟且需浏览器在运行 |
| D4 | 读取本地数据库、执行命令、连内网服务 | 需本地 agent 桥接（Native Messaging） |
| D5 | 后台静默监听剪贴板 | 需用户手势或页面聚焦，无法静默常驻 |
| D6 | 超大文件（数百 MB）无损处理 | 内存天花板；Worker 也只能缓解 |
| D7 | OCR / PDF 深度解析 / Office 高保真转换 | WASM 可做轻量版（tesseract.js、pdf.js），重需求必须服务端 |
| D8 | 无账号无服务端时的跨设备同步 | 只能用 `storage.sync`，且仅适合小体积设置 |

## v1 明确不做（写进 README，避免预期错位）

- 不做登录、不做云同步、不做分享链接。
- 不做任何网络请求（除用户主动触发的外部链接），扩展声明 `host_permissions` 为空。
- 不做 AI 能力（预留 BYOK 开关位，但不实装）。
- 不做系统级快捷键、不做托盘常驻。
