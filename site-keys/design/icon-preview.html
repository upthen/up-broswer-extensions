本页 4 档图标以 data URI 内嵌，离线打开或内置预览都不会破图；npm run icons 会同时刷新图标与这里的内嵌副本，随后 npm run build 把新图标复制进 dist/icons/。
Chrome 会缓存扩展图标，改完记得在 chrome://extensions 点「重新加载」；若工具栏仍是旧图，移除后重新加载一次即可。
