05

设计说明 思路、改动与落地

含两个产品问题的回答；所有建议仅作说明，稿中不实现任何新增功能。

仅样式改动

整体思路

沿用 v3 的「微暖纸感 + 靛蓝墨」设计系统，让两个模块看起来是同一个产品：同一根顶栏、同一套圆角与柔阴影、同一套等宽凭证行、同一套「默认低调、hover / focus 才强调」的交互。

差异只在主体：便签是高密度扫描——小卡片、瀑布网格、摘要截断、操作收起；记事本是低密度沉浸——纯白整页、大标题、宽行距、极轻工具条。一密一疏，切换时布局明显不同。

便签卡片不再内嵌输入框：点击才进详情浮层编辑，既让卡片变小、一屏看更多，也让「复制」成为不需要进入编辑就能完成的高频动作。

与上一版的关键改动

  • 新增一级切换器：顶栏分段控件「便签 / 记事本」，张数徽章并入「便签 8」。
  • 便签由大卡片改小卡片：整列大卡 → n*n 瀑布网格；标题 + 2–4 行摘要，超出省略。
  • 编辑从常驻变按需：卡片内不再放 textarea，点开才出现详情浮层；输入即存不变。
  • 操作收进角标与「⋯」：复制全文 / 复制密码 / 删除 hover 才淡入，窄卡片不溢出。
  • 工具条由两行收为一行：搜索框 + 34px 方形「＋」，窄栏省下约 44px 纵向空间。
  • 新增记事本模块：文件列表 + 整页无边框书写区；宽屏左栏常驻、窄栏顶部下拉。
  • 响应式列数：侧栏 2 列、中宽 3 列、全屏 4 列，同一份卡片组件。

落地到 base.css 的注意事项

  • 顶部注释的 token 全部进 :root；旧 --primary 统一为 --accent；新增 --nav-w / --topbar-h / --seg-h / --card-min。
  • 不改业务逻辑：类名沿用 .topbar / .toolbar / .footer / .toast；新增 .seg / .stickies / .sticky / .detail / .nb / .editor / .file-item 等纯样式类。
  • 瀑布用纯 CSS：.stickies{columns:N;column-gap} + .sticky{break-inside:avoid;display:inline-block;width:100%}；按容器宽度切 2/3/4 列，无需 JS 砌墙。
  • 摘要截断：-webkit-line-clamp:4 + overflow:hidden；white-space:pre-line 保留换行。
  • 详情浮层：用 dialog 或绝对定位浮层；焦点锁在浮层内，Esc 关闭；正文 textarea 保持等宽、resize:vertical、输入即存的串行写入。
  • 记事本书写区：.editor 用 flex:1;min-height:0 撑满剩余宽高；标题与正文 border:0;outline:0;background:transparent，不要套卡片；:focus-visible 只保留插入符。
  • sticky 作用域：顶栏 sticky 置于滚动容器内，--topbar-h 恒定 52px；全屏页不滚动时把顶栏 / 工具条改回 position:static。
  • 功能红线：删除与清空仍走 window.confirm（清空二次确认）；「复制密码」仍由 extractPassword 条件控制；无登录 / 解锁 / 保存按钮 / 联网。
  • 数据红线：稿中密码全为脱敏示意值，落地时切勿写进 src/seed/initialNotes.ts；记事本文档为示意内容，播种逻辑另行处理。
产品问题 01
便签和记事本的数据是否需要互通？例如便签一键「转为文档」。

建议：不做互通，也不提供「转为文档」。本稿不实现该功能。

理由一，心智模型不同：便签是碎片、短、即取即弃，价值在「一眼扫过 + 一键复制」；记事本是长文、持续编辑，价值在沉浸书写。强行打通会让两个模块互相污染定位。

理由二，一份内容两处真相：纯本地明文、无同步、无版本历史，转换即产生副本；用户改了原便签，文档不会跟着变，很容易残留过期凭证，反而扩大明文暴露面，与「请只放开发 / 测试信息」的风险提示相悖。

理由三，成本与边界：需要新增跨模块引用、冲突处理与删除联动，超出「打开即用」的极简基线。若未来确有需求，建议作为独立提案，只提供显式的单向动作（例如用户手动复制内容后新建文档），不做自动关联或双向同步。

产品问题 02
两个模块共用的顶栏 / 切换器，如何不占用侧栏本就紧张的纵向空间？

结论：顶栏合并为一行、高度锁死，切换器不新增任何一行。

① 切换器进顶栏，不另起一行：品牌方块 + 分段控件 + 全屏按钮同处 52px 顶栏；宽屏也只增到 56px。分段控件用 --seg-h 32px，不撑高整行。

② 窄栏做减法：380px 内隐藏产品名文字，只留 26px 品牌方块；「全屏打开」收成图标按钮；张数徽章并入分段标签「便签 8」，省掉一个独立元素。三者都让位给切换器，避免两行顶栏。

③ 模块工具条本来就得有，不因切换器增加：便签工具条由上一版两行收为一行（搜索框 + 方形「＋」，34px）；记事本把「文件切换 + 字数 + 复制」压成同一行 40px，文件列表收成下拉浮层，不常驻占高。

④ 滚动时仍只占一行：顶栏 position:sticky;top:0 且高度恒定；模块工具条紧随其后。整个侧栏固定开销 = 52px 顶栏 + 34/40px 工具条，其余全部留给内容。
