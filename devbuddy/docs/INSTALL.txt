研发好朋友 · DevBuddy  {{VERSION}}
浏览器扩展安装包（Chrome / Edge，Manifest V3）
============================================================

一、安装（推荐方式，约 2 分钟）

  1. 把本 zip 完整解压到一个固定目录，例如：
        D:\Tools\DevBuddy-{{VERSION}}
     解压后该目录里应当能看到 manifest.json、INSTALL.txt 和 dist 文件夹。
     注意：不要只解压出单个文件，也不要在 zip 里直接双击运行。

  2. 打开浏览器，地址栏输入：
        Chrome → chrome://extensions
        Edge   → edge://extensions

  3. 打开页面右上角的「开发者模式」。

  4. 点击「加载已解压的扩展程序」，选择第 1 步解压出来的文件夹。
     选这个文件夹本身，或它里面的 dist 子文件夹，两种都可以，
     本项目为两种目录都准备了可用的 manifest.json。

  5. 出现「研发好朋友 · DevBuddy」即安装成功，
     建议点工具栏拼图图标把扩展固定到工具栏，之后点图标即可打开。

  重要：解压后的文件夹不要删除、改名或移动，否则扩展会失效。
  升级时先在扩展页移除旧版本，再加载新版本目录。

  快捷键：
     Alt + Shift + J   打开全屏工具页
     Alt + Shift + K   打开侧边栏
  如果与其他扩展冲突，可在 chrome://extensions/shortcuts 里修改。

------------------------------------------------------------

二、关于同目录下的 .crx 文件

  .crx 是带签名的 CRX3 包，主要用于企业策略 / 批量部署或自行留档。
  Chrome、Edge 的正式版本默认拦截「非应用商店来源」的 crx，
  直接拖进扩展页面通常会提示安装被阻止 —— 这不是安装包损坏。
  个人安装请使用上面的 zip 解压方式。

------------------------------------------------------------

三、功能一览

  JSON 工具    格式化 / 校验 / 修复 / 压缩 / 键排序 / 转义，
               树形视图、JSONPath 查询、五语言代码生成
  编码转换     Base64 / URL / Unicode / HTML 实体 / JWT 解码
  二维码       生成（PNG、SVG、配色、纠错等级、导出尺寸）
               与解码（选图 / 拖拽 / Ctrl+V 粘贴）

  亮暗主题、紧凑模式、三套入口（弹窗 / 全屏标签页 / 侧边栏），
  三个模块的输入各自保留，切换不丢数据。

------------------------------------------------------------

四、隐私与权限

  完全离线运行，零网络请求。只申请两个权限：
     storage    —— 本机保存最近 20 条输入历史
     sidePanel  —— 打开侧边栏
  host_permissions 为空，不读取网页内容、不上传任何数据。
  JWT 只解码内容、不校验签名；二维码图片只在本机 Canvas 中处理。
