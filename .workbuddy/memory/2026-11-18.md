## 网迹（history-by-domain/）v1.4.0 标签页管理模块：设计决策（grill-me 访谈结论，尚未实现）

参考项目：Zara 的 `zarazhangrui/tab-out`（MIT，MV3 纯扩展，接管新标签页，权限 `tabs`/`activeTab`/`storage`）。用户实际用过，**反馈「接管新标签页太卡、不好用」**，因此明确不采用该形态。其 background.js 在 `tabs.onCreated/onRemoved/onUpdated` 每次全量 `chrome.tabs.query({})` 刷 badge，是卡顿的可疑来源。

已锁定决策：
- **A 形态**：面板顶栏加第三个分段 tab「标签页」（历史/书签/标签页）；不写 `chrome_url_overrides`、不做 popup。模块独立 ES module，切到该 tab 才动态 `import()`，历史/书签首屏零开销。
- **B 权限基线**：manifest 只新增 `tabs`（唯一必需，否则 `chrome.tabs.query` 无 url/title）；不加 `storage` / `activeTab` / host 权限。**零持久化、零 change 监听、零网络请求全部保留**。仅在「标签页」tab 激活且页面可见时 query；刷新时机＝切到该 tab / 切回可见 / 每次关闭后 / 手动刷新按钮。需新增 SPEC §17 覆盖 §10.5、决策 9、§16.11、验收 37。
- **C 分组**：eTLD+1 合并子域，复用 `domain.js`；**必须走 `normalizeItem()` 的协议白名单**（非 http/https → `__local__`），直接调 `getRegDomain()` 会把 `chrome-extension://<id>` 当单标签内网主机单独成组。localhost/IP/内网主机归「本地 / 其他」。每个 tab 一行、不按 URL 去重；面板自身与 `detail.html` 剔除（可复用 `app.js` 已有 `selfTab`）。「本地 / 其他」桶显示、只给行级关闭、**不给整组关闭**、固定排最后。
- **D 关闭**：三条写路径 = 组级「全部关闭」/ 行级「关闭其他」/ 行级「单独关闭」。组级与「关闭其他」均为**全窗口 + 两步确认（确认前 0 次 remove）+ 跳过 pinned**；单条一次点击即关。确认条列出 N 与子域明细，文案写「可 Ctrl+Shift+T 恢复」而非「不可撤销」。点击 tab 行＝按 id 聚焦（必要时 `chrome.windows.update` 带窗口），**不新开**、不走 http/https 协议白名单。特殊桶禁用「关闭其他」以免绕过 C 的决议。
- **E 展示**：沿用卡片墙（圆角 3–4px、图标化行按钮）。卡头「域名 · N 个标签页」+ 带文字的「全部关闭」；默认 3 条预览、卡内展开不跳详情页；组内按 `windowId`→`index` 原顺序；卡片按 tab 数降序、同数按域名 A–Z。重复 tab：**完整 URL 完全相等**（含 hash/query）才算，只读 pill，第 2 个及之后才标，不自动关、不加「只留一个」按钮。关闭后用 toast 提示可恢复。
- **明确不做**：Save for later、记住折叠态、badge 计数、landing pages 独立组、音效/彩带、撤销/回收站、跨源合并。
- **F 工程**：版本 `1.4.0`；新增 `tabs.js`（纯逻辑，可 node 单测）+ `tabs-panel.js`（渲染/写操作/确认/竞态），`app.js` 扩 `activeTab` 三值、`?tab=tabs` 深链、写操作互斥锁扩到第三类；`index.html`/`styles.css` 扩控件与样式；`sw.js`、`domain.js`、`history.js`、`bookmarks.js` 不动。文档同步 `SPEC.md`（新增 §17）、`安装说明.md`、根 `README.md`；验收清单实际续编 **60–75**（49–59 已被书签的 §16.13.5 占用）并重跑 1–59 回归。实现顺序 M11-a~g 参照 §16.10 M10 范式。

已知限制：停留在该 tab 时别处开关标签页不自动刷新；精简 PSL 表口径风险沿用；无痕窗口默认不可见；关光某窗口全部 tab 会连带关闭该窗口（面板所在窗口因面板被排除而保留）。
