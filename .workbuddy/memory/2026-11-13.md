- **安全**：`chrome.storage.local`，密码字段 AES-GCM 密文，域名/用户名/备注明文；主密码 → PBKDF2 + 随机 salt，密钥放 `chrome.storage.session`（内存、worker 回收不丢、关浏览器即清）；一次解锁管一会话，有「立即锁定」；忘记主密码不找回，只给清空重设。解密仅在复制/显示出口。用户中途由「明文」改判为加密，因此 A 分支「不做导入导出」的旧护栏解禁。
- **录入**：v1 不做自动捕获、不注入 content script、不申请 `<all_urls>`；手工录入 + 自动带出当前 host:port（「询问是否保存」退化为「用户主动发起」这一闸门）。另支持 CSV/JSON 批量导入（含 Chrome 密码管理器导出 CSV，解锁→加密→去重→预览确认），以及密文 JSON 导出备份。
- **数据模型**：作用域 = `host[:port]` + 可选 `pathPrefix`（不含 scheme，端口归一化）；展示层按 eTLD+1 折叠子域，但 IP/localhost/内网单标签主机各自独立成组 —— 复用 `history-by-domain/domain.js` 的 PSL，但**不能**复用它把所有 IP 合并进 `__local__` 桶的逻辑。两层结构 scope{key,siteName,env?,tags?,accounts[]} + account{label,username,passwordEnc,note,时间戳,favorite}；唯一约束 scope+label；改密覆盖不留历史。
- **命中**：严格 host:port 精确，不跨子域/端口；pathPrefix 最长匹配优先；同注册域其他作用域折叠兜底；无命中不猜。
- **使用**：v1 只做一键复制（用户名/密码各一按钮），不做自动填充；明文只到剪贴板，不进页面 JS 上下文。
- **载体/权限**：侧栏（日常查复制）+ 全屏标签页（管理/导入导出/设置）；`permissions: storage, sidePanel, tabs, clipboardWrite`，`host_permissions: []`，无 scripting/history/downloads。`tabs` 只用于侧栏跟随切标签（读 URL 不读内容）。Vue3 + TS + Vite，复用 devbuddy 的 `useClipboard.ts` / `downloadText` / sidePanel 唤起与构建脚本。
- **仓库实证**：devbuddy 在仅 `storage + sidePanel` 权限下用 `navigator.clipboard.writeText` 可写剪贴板、用 Blob+`<a download>` 可导出文件；`history-by-domain/SPEC.md:105` 记载按 URL pattern 查标签需要 `tabs` 权限，故该项目改用握手方案（并踩过 worker 回收的坑）。
- **动手前需验证**：`chrome.storage.session` 回收后行为与不落盘、`clipboardWrite` 在无用户手势时能否写剪贴板（决定「复制后 30s 清空」是否成立）、侧栏在 `chrome://` 页面的可用性。
- **残留风险（须写进 README/设置页）**：忘记主密码全库含备份报废；解锁期间同机任何人可复制；剪贴板明文残留；清 profile/卸载即数据消失；导入源 CSV 为明文需自行删除。

## 同日收尾：全屏页卡死修复 + 双模块视觉设计稿（设计稿尚未落地实现）

- **Bug（真机反馈）**：点「全屏打开」永远停在「正在打开便签本…若没有跳转，请点此。」。根因：加载 `site-keys/` 根目录时 `chrome.runtime.getURL('index.html')` 指向根目录 `index.html`，而它是含**内联** `<script>location.replace('dist/index.html')</script>` 的转发页；**MV3 extension_pages 的 CSP 禁止内联脚本**，脚本不执行。**结论：扩展页里不要用内联脚本做跳转，meta refresh 也不如直接生成真页面稳。**
- **修复**：`vite.config.ts` 的 `closeBundle` 把 `dist/index.html` 内容里的 `./assets/` 替换为 `dist/assets/` 后写入根 `index.html`，两类加载方式下 `index.html` 都是可运行的真应用页，无跳转、无 CSP 隐患。`tests/manifest.test.ts` 新增 T-27 四条守卫（无内联脚本/跳转文案、根页含挂载点且资源存在、根页与 dist 页仅前缀不同、全屏入口用 `chrome.tabs.create`）；先跑出 3 条 RED 再修到 GREEN。根 `index.html` 从此是**构建生成物**，已加入 `.gitignore`。当前 `npm test` 7 文件 / **53 用例全绿**、typecheck 零错误、build 成功。
