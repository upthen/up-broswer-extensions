## 同日续二：编辑区从「表单控件」改成「纸面」（设计）

用户贴截图（框住 textarea）说「这块 UI 太奇怪，哪里像个编辑记事本」，并建议请设计来定。诊断：问题不在配色，而在编辑区用了 `1px` 边框 + `--surface-2` 灰底 + 蓝色 focus 环 —— 那是输入控件的语义，3 行内容掉进 500px 高的框里就像一张没填完的表。

改法（对齐本项目记事本模块 `.editor__page` 的既有语言）：

- 正文等宽 13px/1.9（宽屏 14px/1.95），去边框、去灰底、去 focus 环，`caret-color: accent`、`::selection: highlight`；
- 操作栏左侧放「字数 · 更新时间」、右侧按钮，加 1px 下边线分隔 chrome 与纸面；删掉「编辑便签」标签（标题即语境）。
- 没做横格纸背景：12px/1.9 的行高与 repeating-gradient 难严格对齐，错半像素就成廉价假笔记本。

## 记事本改所见即所得编辑（v5.1, site-keys）
- 视图三档「编辑/分栏/预览」收敛为两档「编辑（所见即所得）/源码」；表格按单元格内联编辑。
- 架构：DOM 是编辑期唯一真源，`blocksToMarkdown()` 序列化回 Markdown 纯文本；`docDraft.content` 存储格式不变。只有切文档/撤销才整体重渲染。
- 新增：`src/ui/editor/{rules,caret,serialize,history}.ts` + `src/ui/MarkdownEditor.vue`（645 行）。
- 四个硬坑：①`<script setup>` 里的"顶层变量"是每实例一份，撤销栈必须抽成模块单例（`history.ts`），否则切视图重建就清空；②凡"改 DOM 但不触发 input"的路径（退格合并）必须显式 `emitValue()`，否则切视图按旧内容重渲染、改动被无声还原；③`<li>` 里只允许任务框转换，否则 `<blockquote>` 进 `<ul>`；④多行粘贴不能塞进当前块（会污染标题），要先拆块再插。
- 标题去重：正文首行 `# X` 写回 `doc.title` 并收起标题输入框。
- 安全：全仓已无 `v-html`，`innerHTML` 只接 `renderMarkdown()` 输出。
- 测试：新增 `happy-dom` devDep（不进产物），`tests/{rules,markdownEditor,history}.test.ts` 共 39 条；总数 226 全绿。

## 记事本退回「左源码 / 右预览」（v5.2, site-keys）
- 起因：v5.1 的所见即所得 bug 太多，用户要求改回左源码、右效果的分栏模式。
- 删掉整套 DOM 编辑逻辑：`src/ui/editor/{rules,caret,serialize,history}.ts` 与 `tests/{rules,history}.test.ts` 一并移除；`MarkdownEditor.vue` 从 645 行降到约 100 行。
- 新架构：**Markdown 文本是唯一真源，预览是派生物**。`textarea` 用 `v-model` 绑 `computed({get,set})` 回写父组件（v-model 自带 composition 守卫，中文输入法不用手写状态机），预览只做 `renderMarkdown(value) → innerHTML`。
- 视图三档「分栏 / 源码 / 预览」，默认分栏；用 `v-show` 切显隐，文本域不重建，原生撤销 / 光标都保留。旧值 `wys` 迁移为 `split`、`edit` 迁移为 `source`。
- 布局：`.mdx` 两列 grid，右列 1px 左分隔线并自己滚动；`max-width:899px` 自动叠成上下两栏（没有按宽度隐藏按钮）。`.editor__pane` 改为 `overflow:hidden`，滚动交给两栏。
- 两个细节：①`innerHTML` 重建会把预览 scrollTop 清零，必须「重排前记比例、重排后按比例还原」，否则长文档每敲一个字就弹回顶部；②源码滚动只单向带动预览（rAF 合帧），不做反向同步以免互相拉扯。
- 测试：`markdownEditor.test.ts` 改写为组件级 5 条（用 `createApp` + happy-dom 挂载，验证源码单向进预览、输入回抛、三档只切显隐、XSS 转义）；`design.test.ts` T-44 换成 T-45；总数 193 全绿。
- 版本 0.5.2；主 JS 99.89 KB / gzip 37.30 KB（比 v5.1 少约 12 KB）。截图 `design/render/09-notebook-split-wide.png` / `10-notebook-split-side.png`。
